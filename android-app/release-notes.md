For Mimi, from Yuki. ♡

Install Pocket-Yuki.apk on an Android phone (Android 7 or newer, with a current Android System WebView).

Includes comforting notes, funny photos, reasons to smile, date ideas, daily notes, saved keepsakes, a new 11-item memory album and five video memories. The app's content and fonts are bundled for offline use. The optional daily notification is enabled only when you ask for it.

This is a directly installable test APK signed with the build runner's temporary Android debug key. A future build may require uninstalling this one first, which removes locally saved keepsakes. Your browser may ask you to allow installation from this source. There is no account, subscription or payment. Saved keepsakes stay on the phone. The link to Our Rewind opens the existing website and needs internet.
